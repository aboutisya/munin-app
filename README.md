# Мунин

Записывает рабочие встречи на Mac, расшифровывает их локально и готовит саммари через Claude Code по вашей подписке.

- Две дорожки: ваш микрофон и звук звонка (Zoom, Толк, Meet, Telegram — любые приложения).
- Распознавание и разделение по спикерам — на вашем Mac, без облака.
- Саммари, решения, задачи, темы, схемы, тональность и разбор вашей речи в конфликтных местах — через `claude` по подписке. Без API-ключей.
- Публичное саммари для Mattermost, Slack или Telegram — одной кнопкой в буфер.
- Сквозной список задач, поиск по всем встречам, узнавание людей по голосу.

Мунин — ворон Одина, чьё имя значит «память». Рабочее имя проекта — «Мнемозина»: так называются модули и идентификатор `local.mnemosyne.app`.

## Что нужно

- Mac на Apple Silicon (M1 и новее), macOS 15 или новее.
- [Claude Code](https://docs.claude.com/en/docs/claude-code), вход по подписке Pro, Max или Team: в Терминале `claude /login`.
- Около 2,5 ГБ на диске: распознавание и модель скачиваются при первом запуске.

## Установка

1. Скачайте `Munin-<версия>.dmg` со страницы [Releases](../../releases), откройте и перетащите «Мунин» в «Программы».
2. Запустите. macOS скажет, что не может проверить разработчика: приложение подписано, но не нотаризовано в Apple.
3. Откройте **Системные настройки → Конфиденциальность и безопасность**, внизу у сообщения про «Мунин» нажмите **«Всё равно открыть»** и подтвердите паролем. Это нужно один раз.

Если кнопки нет, можно снять карантин в Терминале:

```sh
xattr -dr com.apple.quarantine /Applications/Мунин.app
```

## Первый запуск

Онбординг из трёх шагов:

1. **О вас.** Имя и чем занимаетесь — Claude учтёт это при разборе. Мессенджер для публичного саммари и папка встреч (по умолчанию `~/Meetings`).
2. **Доступы и инструменты.** Микрофон, звук приложений, календарь, уведомления. Проверка Claude Code. Кнопка «Установить» распознавание: Python, mlx-whisper и модель Whisper, около 2 ГБ, один раз.
3. **Ваш голос.** 20 секунд чтения вслух — чтобы на встречах в переговорке отличать вас от остальных. Можно пропустить.

Запись — ⌃⌥⌘R или ворон в строке меню. Перед встречей из календаря придёт уведомление «Записать?».

Предупреждайте собеседников, что встреча записывается.

## Что куда уходит

- Аудио, транскрипты, отпечатки голосов, поиск — только на вашем Mac.
- В Claude по вашей подписке уходит транскрипт встречи (для разбора) и короткая выжимка без оценок людей (для публичного саммари). Встречу можно пометить «Не анализировать».
- Приложение не шлёт телеметрию.

Расход: часовая встреча — по оценке около 55 тыс. токенов на вход и 12 тыс. на выход на разбор и ещё около 25 тыс. на публичное саммари. Расход за день и неделю виден в настройках.

## Где что лежит

- Встречи: `~/Meetings/<дата>_<название>/` — аудио, `transcript.md`, `summary_personal.md`, `summary_public.md`, схемы. Markdown читается и без приложения.
- Распознавание: `~/Library/Application Support/Munin/whisper`, модель — в кэше Hugging Face `~/.cache/huggingface`.
- Скиллы `meeting-analysis` и `meeting-public` приложение ставит в `~/.claude/skills`. Если вы их правили, при обновлении старая версия сохранится рядом как `SKILL.md.<версия>.bak`.
- Необязательный сторонний скилл [ru-text](https://ru-text.org): если он у вас установлен, публичное саммари можно вычитывать им (переключатель в настройках).

## Удаление

Удалите «Мунин» из «Программ» и, если нужно, папки `~/Library/Application Support/Munin`, `~/.claude/skills/meeting-analysis`, `~/.claude/skills/meeting-public`. Встречи в `~/Meetings` останутся.

## Разработка

```sh
make cert      # один раз: локальный сертификат подписи, чтобы разрешения не сбрасывались после пересборки
make app       # build/Мунин.app (скачает uv при первой сборке)
make run       # собрать и запустить
make test      # юнит-тесты
make dmg       # build/Munin-<версия>.dmg для раздачи
make icon      # пересобрать иконку из Sources/Mnemosyne/Raven.swift
make demo      # демо-встреча со всеми вкладками в ~/Meetings
```

Xcode не нужен, хватает Command Line Tools (Swift 6.1). Техническое решение и заметки по этапам — [docs/munin-tech-design.md](docs/munin-tech-design.md).

Модули:

- `Sources/MnemosyneCore` — запись (Core Audio tap, микрофон), хранилище, календарь, склейка транскрипта, модели анализа, задачи, голоса.
- `Sources/MnemosynePipeline` — распознавание (mlx-whisper через `uv`), диаризация (FluidAudio), вызовы `claude`.
- `Sources/Mnemosyne` — строка меню, главное окно, настройки, онбординг.
- `Skills/` — скиллы Claude, которые приложение ставит пользователю.

Логи: `log stream --predicate 'subsystem == "local.mnemosyne"'`.

Переменные окружения для отладки:

- `MNEMOSYNE_ROOT` — другая папка встреч.
- `MNEMOSYNE_PROCESS_ALL=1`, `MNEMOSYNE_ANALYZE_ALL=1`, `MNEMOSYNE_PUBLISH_ALL=1` — обработать, проанализировать или сделать публичное саммари для всех встреч и выйти; итог в `process.txt`, `analyze.txt`, `publish.txt`.
- `MNEMOSYNE_SETUP_WHISPER=1` — поставить окружение распознавания без интерфейса, итог в `setup.txt`.
- `MNEMOSYNE_RERENDER=<id>` — пересобрать Markdown и PNG схем встречи.
- `MNEMOSYNE_OPEN_MAIN=<вкладка|tasks>`, `MNEMOSYNE_OPEN_ID=<id>`, `MNEMOSYNE_OPEN_SETTINGS=1`, `MNEMOSYNE_OPEN_ONBOARDING=1`, `MNEMOSYNE_ONBOARDING_PAGE=<0–2>`, `MNEMOSYNE_SHOW_POPOVER=1` — открыть окно для скриншота.
- `MNEMOSYNE_ENROLL_FILE=<аудио>` — отпечаток голоса из файла и близость к спикерам, итог в `enroll.txt`.
- `MNEMOSYNE_CLAUDE_PATH=<путь>` — подставной `claude` для проверки очереди.
- `MNEMOSYNE_SELFTEST=<секунды>` — тестовая запись (`make selftest`).
